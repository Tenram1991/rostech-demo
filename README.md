# Управленческий дашборд закупок

Аналитическая надстройка над АС ФЗД | ЕПОЗ | ЕНС для заместителя генерального директора по закупкам.

## 🚀 Демо

[Открыть дашборд](https://ВАШ_USERNAME.github.io/rostech-demo/)

## 📊 Функциональность

### 9 вкладок аналитики:
1. **Главная** — сводная панель с ключевыми метриками и центром уведомлений
2. **Доходные договоры** — 10 контрактов ГОЗ и коммерческих
3. **Исполнение контракта** — 50 расходных договоров с этапами
4. **Логистика** — 36 рейсов с интерактивной картой маршрутов
5. **Склад** — 60 позиций ТМЦ с резервами ГОЗ
6. **Команда** — 15 сотрудников с KPI и обучением
7. **Финансы** — отдельные счета ИГК, платежный календарь, кассовые разрывы
8. **Сводные риски** — 30 рисков с матрицей и тепловой картой
9. **Исполнение ГОЗ** — 6 ИГК с дорожной картой

### Ключевые возможности:
- 🔴 **Центр уведомлений** — автоматическая агрегация критических событий
- 📈 **Sparklines** — мини-графики трендов в KPI-карточках
- 📥 **Экспорт данных** — CSV/JSON из любой таблицы
- 🔗 **Перекрёстные ссылки** — навигация между связанными вкладками
- 📱 **Адаптивный дизайн** — корректное отображение на всех экранах
- 🗺️ **Интерактивная карта** — агрегированные направления с пульсацией проблемных

## 🛠 Технологии

- **Frontend:** React 18 + TypeScript
- **Сборка:** Vite 5
- **Стилизация:** Tailwind CSS
- **Графики:** Recharts
- **Иконки:** Lucide React
- **Деплой:** GitHub Pages + GitHub Actions
